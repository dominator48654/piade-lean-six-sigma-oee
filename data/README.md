# Data Directory

This directory contains the raw data and exported data.

## raw/
Place the raw data files here:
- `raw_data.csv`
- `sequences_1h_data.csv`

These files are not included in the repository due to their size and licensing.
Please download them from the Kaggle dataset (TODO: add link) and extract them into this directory.

## exports/
Contains the exported CSV files from the SQL views and Python scripts.
These are generated by running the SQL export script and the Python pipeline.
